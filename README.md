# BolsaIA V29

V29 mantém a identidade visual e as funcionalidades da V28 e corrige os atalhos de navegação.

## Correção dos atalhos
- 🏠 Início: volta ao topo.
- ⚡ Scanner: rola diretamente para o Scanner.
- 📊 Análise: rola diretamente para a área de análise detalhada.
- ⚙️ Config: abre a tela de configurações.
- 👤 Login: abre a tela de login demonstrativo.

Os atalhos de Início, Scanner e Análise usam âncoras da própria página, evitando o comportamento anterior em que o botão apenas alterava o estado e a tela parecia não mudar.

## Observação
O app continua sendo demonstrativo e não envia ordens reais.

# BolsaIA v1

Painel experimental para análise técnica de ações.

## Executar

```bash
pip install -r requirements.txt
streamlit run app.py
```

A versão atual usa dados simulados. Para operar com cotações reais, conecte um provedor de Market Data autorizado/licenciado em `dados.py`.

## Indicadores
- MM20
- MM50
- RSI 14
- volume médio
- pontuação experimental de tendência
